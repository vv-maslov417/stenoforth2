Стенографический Forth (StenoForth) на базе SPF-4.29: кратко о некоторых возможностях

1. StenoForth помогает снизить нагрузку на кратковременную память программиста. Достигается это за счёт сокращения динамического инструментального контекста при разработке программ: освободившееся место в кратковременной памяти можно направить на работу с динамическим контекстом решаемых задач. В частности, за счёт того, что:
1.1. используются статические локальные переменные различных типов вместо слов манипуляции параметрами на стеке;

1.2. упрощается работа с контекстными словарями: вместо выстраивания иерархии контекстов на стеке контекстов применяется переключение контекстов поиска.

2. Введены макросы как инструмент минимизации текста программ (они допускают практически неограниченную вложенность). Это позволяет сокращать текст программ, а также поддерживать программирование сверху вниз. Кроме того, макросы дают возможность выполнять инлайн-подстановки на уровне инструкций процессора, что повышает производительность кода.

3. Одно определение, состоящее из опознавателя имён группы и генератора кода для этой группы, позволяет создавать код сразу для целой группы литеральных имён. Когда во входном потоке появляется литеральное имя из такой группы, оно опознаётся, и соответствующий код формируется — а при необходимости и выполняется — «на лету».

4. Реализована концепция формирования определений слов глобальной видимости через создание локальных слов, область видимости которых ограничена только формируемым определением. Имена локальных слов различного типа в локальном словаре, привязанном к формируемому определению, уничтожаются по завершении его формирования. Это позволяет задавать небольшое количество глобальных имён, не засоряя глобальный словарь Forth, и упрощает именование локальных слов. В итоге программа складывается как небольшой набор слабо связанных глобальных слов с высокой степенью абстракции. Реализована возможность объединения областей видимости
таких слов.

5. Реализована возможность быстрого создания определений слов с односимвольным представлением входящих слов и их контекстов.

6. Введено ограниченное типизирование статических локальных переменных и локальных слов для упрощения синтаксиса при их использовании.

7. Реализована возможность писать определения с использованием встроенного форт-ассемблера с коротким представлением инструкций.

При этом все возможности SP-Forth сохраняются.

Получить расширенную форт-систему(Стенографический Forth на основе SPF-4.29) можно следуя указаниям в файле Spf4290.f
