stenoforth2

Стенографический Forth(StenoForth) на основе SPF-4.29, кратко о некоторых возможностях.

1)StenoForth помогает уменьшить нагрузку на кратковременную память программиста.
Это достигается за счёт сокращения динамического инструментального контекста
при разработке программ. В результате освобождается место в кратковременной памяти, которое можно использовать
для работы с динамическим контекстом решаемых задач.
В частности это достигается:

1)1 За счет использования статических локальных переменных разных типов вместо слов манипуляции параметрами на стеке.
1)2 За счет упрощения использования контекстных словарей, а именно, за счет переключения контекстов поиска вместо
выстраивания иерархии контекстов на стеке контекстов.

2)Введены макросы в качестве инструмента для минимизации текста программ(макросы допускают практически неограниченную вложенность),
что позволяет минимизировать текст программ, а также поддерживать программирование сверху-вниз.
Кроме того макросы позволяют делать инлайн подстановки на уровне инструкций процессора,
что повышает производительность кода программы.

3)Возможно создание кода для группы литеральных имен одним определением, состоящим из опознавателя имен этой группы и
генератора кода для имен этой группы. При появлении во входном потоке литерального имени из определенной группы таких
имен это имя будет опознано и будет сформирован (и если требуется то и выполнен) соответсвующий код "на лету".

4)Реализована концепция формирования определений слов глобальной видимости с помощью создания локальных слов
с областью видимости только внутри формируемых определений. Имена локальных слов различного типа в локальном словаре,
привязанном к формируемому определению после окончания формирования определения уничтожаются.
Это позволяет определять небольшое количество глобальных имен, не засоряя глобальный словарь FORTH,
и упрощает именование локальных слов. Эта концепция позволяет формировать программу как небольшой набор слабо 
связанных глобальных слов с высокой степенью абстракции.
 
4)1 Имеется возможность для связывания таких глобальных определений в группы, внутри которых есть общий доступ
к локальным именам глобальных слов таких групп.

4)2 После включения в группу последнего такого определения словари глобальных определений группы затираются.

5)Возможность быстрого создания определений слов с односимвольным представлением входящих слов и их контекстов.

6)Типизирование статических локальных переменных и локальных слов для упрощения синтаксиса при их использовании.

7)Возможность писать определения с использованием встроенного форт-ассемблера с коротким представлением инструкций.

При этом все возможности SP-Forth сохраняются.

Получить расширенную форт-систему(Стенографический Forth на основе SPF-4.29) можно следуя указаниям в файле Spf4290.f
